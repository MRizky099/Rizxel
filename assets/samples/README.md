# Sample models

Made with Rizxel itself: `cargo run -p rizxel-app --example sample_model -- --all
assets/samples` writes them from code (`rizxel-app/examples/sample_model.rs`). Open them
with *File ▸ Open...* or by dropping them on the window.

| File | Shows |
|---|---|
| `demo.rzxl` | The README's demo: a stepped pyramid, pillars, and a group with a sphere shape layer and a cropped, half-transparent linked clone. |
| `lantern.rzxl` | Render mode: glass panes (transmission), a glowing flame (emission), a dusk sky, rounded voxels, bloom. Press `F5`. |
| `tree.rzxl` | Groups and procedural layers: the crown is a group of sphere shape layers, one of them a linked clone. |
| `cottage.rzxl` | A house in layers inside a group: walls, glass windows, door, roof, gables and chimney; renders with the Brick shape. |
