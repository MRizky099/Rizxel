rizxel, redesigned

A Hallmark audit of Rizxel 0.11.0 in app scope, from the README screenshots, rizxel-ui/src/theme.rs and the panels. The mock on the left is the proposal: same shell, same tools, same docking, a new system. Click the viewport to place voxels, switch tools and ops, and flip to Render.

the read

What it is for
Pixel artists building voxel models: place, paint and organise voxels, then path trace a still.
What works and stays
The shell (title bar, option bar, tools rail, docked panels, status bar), the Model and Render split, the view cube, the live counts and tool hint in the status bar, Inter-class sans with Phosphor icons, and one token module in theme.rs.
What reads as borrowed
The palette is VS Code Dark+ (#1e1e1e, #252526, #007acc) plus Tailwind stock swatches (#38bdf8, #fbbf24, #f87171). The brand’s own ultramarine, the blue of the voxel R, appears nowhere in the interface.
What is broken
Muted text misses contrast on panels, some labels are 9 and 10px, and the amber of the model bounds is reused for every status hint.

findings

  • 40 floor

    TEXT_MUTED #888 on BG_PANEL #252526 is 4.32:1, on BG_HEADER 3.87:1. It carries layer counts, hints and the active layer line.

    theme.rs:24, sidebar.rs:990, sidebar.rs:822

    Muted ink at L 71% on a tinted panel, 5.6:1.

  • 40 floor

    ACCENT #007acc as a line or text on panels is 3.40:1; white on it is 4.51:1, a hair over.

    theme.rs:28

    Split the accent: a fill (ultramarine, light ink on it) and a line (L 72%) for outlines, tabs and the active tool.

  • 75 reflex

    Functional text at 9 and 10px: favourite slot numbers, layer counts, card captions, viewport labels.

    sidebar.rs:160, sidebar.rs:1003, references.rs:349, start.rs:231, viewport.rs:1535

    11px floor for labels, 12px for readouts in Geist Mono.

  • 74 reflex

    Stock swatches as tokens: sky-400, amber-400, red-400, plus VS Code blue. Neutrals have zero chroma.

    theme.rs:9 to 38

    Mix every token in OKLCH from one hue (280) with chroma 0.012, low enough to judge palette colours true.

  • 54 floor

    A caption row, “Tool Options”, sits above the option bar and names it. It costs about 22px of height and says nothing the bar does not.

    dock.rs:74

    Drop the caption when the panel is docked in its default place; keep the name for its tab when floated.

  • state

    The status hint is drawn in BOUND amber with a warning glyph. A hint is not a warning, and the same amber marks the model bounds in the viewport.

    status.rs:97

    Hints in ink-2 with key caps; amber only for the bounds, danger red only for errors.

  • 69 reflex

    Unsaved is said three times: an asterisk in the tab name, a dot on the tab and a bullet in the window title.

    tabs.rs, top_bar.rs

    One dot on the tab that turns into the close button on hover.

  • F4 finish

    Three full-width buttons under the layer tree (Merge visible, Delete hidden layers, Lock all layers) look alike, and the destructive one is styled like the others.

    sidebar.rs:792 to 810

    A layer menu (the three dots) holds them; delete is red and asks first.

  • 39b reflex

    Layer action icons are about 16px targets with no labels; the palette grid is clipped mid row with no sign it scrolls.

    sidebar.rs

    30px icon targets with tooltips, a labelled Add layer button, a well around the swatches with its count above it.

  • consistency

    The rail ends with “2D”, a lone dash and a shield: text, punctuation and a pictogram for two toggles (Slice Mode and Mask Mode).

    tools.rs:82 to 160

    Two toggles that pair an icon with a short state label.

  • layout

    Render settings use six tabs in a 3 by 2 grid, and the preset row needs a dropdown, a name field and a save button.

    render.rs:44 to 49

    Disclosure sections with their current value in the summary, one preset picker with save in its menu, Render pinned to the foot of the panel.

what the mock changes

  1. Document tabs move into the title bar and the caption row goes: the viewport gains about 58px.
  2. One signal colour, the brand ultramarine, marks the active op, the selected layer, the focus ring and the Render button. Nothing else is blue.
  3. A near neutral ground tinted toward the brand’s slate, so palette colours still read true.
  4. Geist for the interface, Geist Mono only for measured values: coordinates, counts, hex, samples.
  5. The viewport keeps its own colour group (ground, grid, bounds, axes), separate from the chrome.
  6. An empty layer says what it is for and offers the one action that fills it.

light mode

Worth adding as a choice, not as the default. Voxel and 3D editors stay dark because the model is the brightest thing on screen and colours are judged against a quiet surround. Light chrome helps in bright rooms, for people who read dark text more easily, and for screenshots in docs. The sun button in the bar previews it.

  1. Settings offers Dark, Light and Follow system; Dark stays the default.
  2. Only the chrome changes. The viewport keeps a mid grey ground, so a model never shifts colour with the theme; Render mode keeps its own backgrounds.
  3. Same hue, same brand fill. Panels go lighter than the ground and wells darker, the reverse of dark, and every text pair stays above 5:1.
  4. Lines and focus take a deeper ultramarine; danger deepens to a brick red.
