# Reference Images

Reference images are PNG or JPEG concept art shown on a plane in the viewport, to model
over. They are saved inside the `.rzxl` file.

Add them with **Add images...** (onto the plane the camera faces most) or by dropping
image files on the viewport.

| Control | Effect |
|---|---|
| Eye, lock | Show or hide; lock in place. `Alt+R` hides or shows all. |
| Rows | Double-click renames; drag changes the draw order; right-click for more. |
| **Plane** | *Front / back* (XY), *Floor* (XZ) or *Side* (YZ). |
| **Offset**, **Size** | The position on the plane and along its normal, and the size in voxels (*Keep the aspect ratio*, *Pixels per voxel*). |
| **Snap plane** | Move the plane to a face of the bounds. |
| **Orient** | Rotate 90°, *Flip H*, *Flip V*. |
| **Opacity**, **Depth** | Transparency; draw behind the model (depth-tested) or on top. |
| **Slice Mode** | Always shown, hidden while slicing, or shown only while slicing. |
| **Reset Size**, **Center**, **Replace Image...**, **Duplicate**, **Delete** | As named. |
| Align the work plane | Puts the work plane on the reference, to draw onto it. |
