# Status bar

From left to right:

- The cursor position (`X Y Z`).
- *Voxels*: the visible voxel count, and *Selected*: the selected voxel count.
- *Mask Mode* when the selection protects voxels.
- *Bounds*: the model size.
- The active tool's hint, or the last message (saved, exported, why an edit was
  refused…).
