# Panels

Every panel docks, floats and joins tab groups (see [The interface](../interface.md)).
*View ▸ Panels* shows or hides them.

| Panel | Mode | Page |
|---|---|---|
| Viewport | both | [Viewport](viewport.md) |
| Tools, Options | Model (Options also in Render) | [Tools and Options](tools-and-options.md) |
| Color Palette | Model | [Color Palette](palette.md) |
| Layers | Model | [Layers](layers.md) |
| Reference Images | Model | [Reference Images](references.md) |
| Bound Model | Model | [Bound Model](bounds.md) |
| History | both | [History](history.md) |
| Render | Render | [Render](render.md) |

The [status bar](status-bar.md) is always shown.
