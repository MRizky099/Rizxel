# Rizxel User Guide

Rizxel is a voxel editor for pixel-art style 3D models. You model with voxel tools,
organize the model in layers, and render it with a GPU path tracer, all in one app. It
reads and writes the formats of MagicaVoxel, Goxel and Qubicle, and exports meshes for
games and 3D printing.

![Model mode: tools, viewport, palette and layer tree](https://raw.githubusercontent.com/MRizky099/Rizxel/main/docs/images/readme/model_mode.png)

This guide covers version **0.10** (Beta 2). Rizxel is still a beta: please report
problems in the [issue tracker](https://github.com/MRizky099/Rizxel/issues) (*Help ▸
Report an Issue*).
