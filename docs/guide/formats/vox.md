# MagicaVoxel .vox

| | |
|---|---|
| **Import** | Each shape instance becomes a layer. Groups, hidden flags and the palette come along; repeated instances of a model become linked clones. |
| **Export** | One model per layer (shapes, clones and crops baked in), with layer names, hidden flags and the palette. Groups become named, nested group nodes. |

MagicaVoxel is Z-up; Rizxel rotates the model on the way in and out. Materials and
render settings are not exchanged.
