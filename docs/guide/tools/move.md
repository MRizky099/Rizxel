# Move

**Key:** `M` · [All tools](index.md)

Drag to move the selection, or the whole active layer when nothing is selected.

| Option | Effect |
|---|---|
| **Drag mode** | *Move* moves voxels; *Resize* drags a face of the bounds to grow or shrink the model area. |
| **Overwrite** | A moved selection replaces the voxels it lands on; off, the move stops before them. |

For exact moves, rotations and scaling use the [Transform](transform.md) tool.
