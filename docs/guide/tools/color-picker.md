# Color Picker

**Key:** `C` · [All tools](index.md)

Click a voxel to make its color the selected palette color. `Ctrl` + click copies the
voxel's color into the selected swatch instead.

| Option | Effect |
|---|---|
| **Sample all layers** | Pick the topmost visible voxel instead of the active layer's. |

Every tool picks with `Alt` + click, so you rarely need to switch to this tool.
