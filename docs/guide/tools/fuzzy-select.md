# Fuzzy Select

**Key:** `W` · [All tools](index.md)

Click a voxel to select the connected voxels of a similar color (a 3D magic wand).
`Shift` adds to the selection, `Ctrl` subtracts.

| Option | Effect |
|---|---|
| **Entire layer** | Select matching voxels anywhere in the layer, not only connected ones. |
| **Use color** / **Threshold** | Stop at voxels of a different color; the threshold sets how close colors must be. |
| **All layers** | Flood through the voxels of every visible layer. |
| **Mask** | *Set*, *Add* or *Sub*. |

The selection buttons (Cut to Layer, Copy to Layer, Deselect, Delete) work as in the
[Selection](selection.md) tool.
