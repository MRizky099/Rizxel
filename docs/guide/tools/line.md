# Line

**Key:** `L` · [All tools](index.md)

Draws straight lines, polylines and curves with the brush tip.

| Mode | How |
|---|---|
| **Line** | Drag from the start to the end. |
| **Polyline** | Click each point; right-click or double-click ends the line. |
| **Curve** | Drag the line, then drag again to bend it. `Enter` applies, `Esc` cancels. |

| Option | Effect |
|---|---|
| **Connectivity** | *Diagonal*, *Pixel perfect* or *Solid* steps. |
| **Brush** shape and size | The tip drawn along the line (shared with the Brush). |
| **Symmetry** | Mirror the line. |
