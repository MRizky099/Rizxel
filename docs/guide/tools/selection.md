# Selection

**Key:** `R` · [All tools](index.md)

Selects voxels with a 3D box.

| Option | Effect |
|---|---|
| **Mode** | *Drag* selects what you drag across; *Box* places an adjustable box: click a voxel, then drag its arrows or faces. `Enter` applies the box. |
| **Mask** | *Set*, *Add* or *Sub*: how the new box combines with the selection (or hold `Shift` / `Ctrl`). |
| **All layers** | Select the voxels of every visible layer inside the box. |
| **Position / Size** | Box mode: the box's corner and size in voxels. |
| **Cut to Layer**, **Copy to Layer** | Move or copy the selection to a new layer. |
| **Deselect**, **Delete** | Clear the selection, or delete the selected voxels. |

The *Selection* menu adds Select All, Invert, Grow, Shrink, By Color and Mask Mode.
